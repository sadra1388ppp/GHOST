# GHOST

Offline-first digital and field investigation lab for Windows.

> Every trace tells a story.

## Status

Project foundation is being built. The first milestone is a dark WPF desktop shell, local SQLite persistence, evidence integrity tools, and an investigation relationship board.

## Planned stack

- C# / WPF
- .NET 10
- SQLite with Entity Framework Core
- MVVM architecture
- Local evidence vault

## Safety and integrity

GHOST is designed for authorized investigations and controlled lab environments. Hashes help detect file changes but do not independently prove authenticity. Preserve originals and document collection methods.
